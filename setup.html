💰 Setup - Mis Finanzas

Sigue estos pasos para crear la tabla en Supabase:

Paso 1: Copia este SQL

Copia todo el código de abajo:

CREATE TABLE IF NOT EXISTS finance_data (
  id TEXT PRIMARY KEY,
  data JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE finance_data ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow all" ON finance_data;

CREATE POLICY "Allow all" ON finance_data
  FOR ALL
  USING (true)
  WITH CHECK (true);

INSERT INTO finance_data (id, data, updated_at)
VALUES ('main', '{}'::jsonb, now())
ON CONFLICT (id) DO NOTHING;

Paso 2: Ejecuta en Supabase

  1. Ve a supabase.com/dashboard
  2. Selecciona tu proyecto
  3. Ve a SQL Editor en el menú lateral
  4. Pega el SQL y haz clic en Run

Paso 3: Verificar

Haz clic en verificar para comprobar que la tabla se creó:

⚠️ Después de crear la tabla, abre tu app principal (index.html) y ejecuta el script de migración en la consola.

Script de Migración

Una vez creada la tabla, abre la app y ejecuta esto en la consola (F12):

(async () => {
    const data = JSON.parse(localStorage.getItem('financeAppData'));
    if (!data || Object.keys(data.months).length === 0) {
        alert('No hay datos en localStorage para migrar');
        return;
    }
    const { error } = await app.supabase.from('finance_data').upsert({
        id: 'main',
        data: data,
        updated_at: new Date().toISOString()
    }, { onConflict: 'id' });
    if (error) alert('Error: ' + error.message);
    else alert('✅ Datos migrados correctamente');
})();
